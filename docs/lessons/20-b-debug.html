هييجي يوم الكود يتبني، ويتحرق، ومفيش حاجة تحصل. الدرس ده مش نظري: ده الترتيب اللي بمشي بيه لما ده يحصل، من الأرخص للأغلى. أغلب المشاكل بتتحل في أول تلات خطوات.

1. الشريحة عايشة أصلًا؟

قبل أي كود: VDD على الرجلين (11 و 32) و VSS على الرجلين (12 و 31) في الـ DIP40؟ ناس كتير بتوصل جنب واحد بس. مقاومة الـ 10k على MCLR؟ الكريستالة قريبة من الرجول ومعاها المكثفين؟

أسهل اختبار: برنامج من 3 سطور يومض ليد على رجل مختلفة، من غير أي درايفر. لو ومض، الهاردوير والفيوزات تمام، والمشكلة في كودك. لو مومضش، متبصش في الدرايفر خالص.

2. السرعة صح؟

الليد بتومض بس الوقت غلط؟ قيس: ومضة كل ثانية، عدّ 10 ومضات بالساعة. لو أبطأ 4 مرات، يبقى _XTAL_FREQ مكتوب بسرعة الـ PLL والفيوز مش PLL، أو العكس. لو أبطأ 8 مرات وإنت على الداخلي، نسيت OSCCON.IRCF.

3. الدالة رجّعت إيه؟

ده سبب إن كل الدوال بترجّع نتيجة. في الـ debugger:

Std_ReturnType r = led_initialize(&led_red);
/* breakpoint هنا: r == E_OK ؟ */

لو E_NOT_OK، الغلط في الإعدادات اللي بعتها (بورت غلط، رجل برّه المدى، NULL). ده بيوفّر عليك تدوّر في الهاردوير.

4. الريجسترات بتقول إيه؟

افتح SFRs. الرجل اللي المفروض تنوّر: TRIS بت بـ 0؟ LAT بت بـ 1؟ لو آه والليد مطفية، المشكلة برّه الشريحة (الليد مقلوبة، المقاومة مش متوصلة، الرجل اللي في الكود مش اللي في السلك). لو لأ، المشكلة في الكود، وحط breakpoint في الدالة اللي المفروض تكتبه.

ADCON1 كمان: لو بتقرا زرار، الـ PCFG بيخلّي الرجل دي Analog؟

الحيلة اللي بتنقذ

لو مفيش debugger ولا UART، ليد واحدة بتبقى شاشتك. ومّضها عدد مرات حسب المكان اللي الكود وصله، أو نوّرها لو دالة رجّعت E_NOT_OK:

if (E_OK != gpio_pin_setup(...)) {
    LATDbits.LATD7 = 1;    /* ليد الخطأ */
    while (1) { }          /* وقف هنا علشان تشوفها */
}

بدائية، بس اشتغلت في مشاريع ناس كتير قبل ما يبقى فيه debuggers رخيصة.

أكتر غلطة في الديباج نفسه

تغيّر 3 حاجات مرة واحدة وتجرّب. لو اشتغلت مش هتعرف أنهي صلّحت، ولو مشتغلتش مش هتعرف لو واحدة منهم بوّظت حاجة تانية. حاجة واحدة كل مرة.

TRISC.0 = 0 و LATC.0 = 1 في الـ SFRs، والليد مطفية. تدوّر فين؟

الريجسترات بتقول إن الشريحة عملت اللي عليها.

تمرين: لاقي الغلط

الكود ده الزرار فيه دايمًا 0. فيه غلطتين:

void main(void) {
    gpio_pin_setup(PORTB_INDEX, GPIO_PIN0, GPIO_DIRECTION_INPUT, GPIO_LOW);
    while (1) {
        logic_t b;
        gpio_pin_read(PORTB_INDEX, GPIO_PIN0, &b);
        if (GPIO_LOW == b) { led_on(&led); }
    }
}
اعرض الحل

1. مفيش pull-up: الزرار بين الرجل والأرضي، ومن غير gpio_portb_pullup_enable() (أو مقاومة خارجية) الرجل سايبة. 2. الليد عمرها ما اتعملها led_initialize، فرجلها لسه Input. وفيه ملاحظة تالتة: النتايج كلها متجاهلة؛ لو كان فيه if (E_OK != ...) كان ممكن تشوف. أما الـ Analog فـ gpio_pin_setup بتحلّها لوحدها، بس gpio_init() أول سطر عادة كويسة.
